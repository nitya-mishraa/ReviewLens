# ReviewLens — User Flow

## Primary User

Online fashion shopper evaluating a product before purchase.

---

## User Journey

### 1. Discover Product

User opens a fashion product on Myntra.

↓

### 2. Evaluate Product

User sees the existing product information:

- Product images
- Product description
- Rating
- Reviews
- Size / fit information

↓

### 3. ReviewLens Appears

ReviewLens presents a Product Reality Snapshot based on
recurring customer experiences.

↓

### 4. Understand Key Signals

User can quickly identify:

- What customers liked
- What customers commonly disliked
- Recurring product concerns
- Important expectation mismatches

↓

### 5. Verify the Insight

User can open the supporting reviews behind each insight.

This keeps the summary transparent and prevents the user from
blindly trusting an automated interpretation.

↓

### 6. Make Purchase Decision

User decides whether to:

- Add to Bag
- Check another product
- Read more reviews
- Continue shopping

---

## User Flow in One Line

Product Discovery
→ Product Evaluation
→ ReviewLens Snapshot
→ Insight Verification
→ Purchase Decision

---

## PM Objective

The objective is not to force users towards purchase.

The objective is to reduce the effort required to understand
customer experiences and help users make more informed decisions.
