# ReviewLens — MVP Scope

## MVP Goal

Help shoppers understand the most important recurring customer
experiences for a product without reading a large number of reviews.

---

## Core MVP Features

### 1. Product Reality Snapshot

A compact summary showing the most important recurring customer
experiences for the product.

Example:

- ✓ Customers generally liked the appearance
- ⚠ Fabric was frequently described as thinner than expected
- ⚠ Some customers reported fit issues

---

### 2. Aspect-Level Insights

Reviews are grouped into meaningful product aspects such as:

- Fit / Size
- Fabric / Quality
- Colour / Appearance
- Product-photo Match
- Comfort
- Durability

The system surfaces the aspects with the strongest recurring signals.

---

### 3. Positive + Negative Signals

ReviewLens should not only highlight complaints.

It should show both:

**What customers liked**

and

**What customers were concerned about**

This prevents the feature from becoming a "complaint detector."

---

### 4. Supporting Review Evidence

Every major insight should allow the shopper to see the reviews
that contributed to that insight.

Example:

**Fabric may feel thinner than expected**

[View supporting reviews]

---

### 5. Recency Signal

Where sufficient data exists, ReviewLens should distinguish between
recent and older feedback.

This prevents an outdated issue from being presented as if it is
still equally relevant.

---

## Out of MVP Scope

The first version will NOT include:

- AI-generated product recommendations
- Personalised shopping recommendations
- Virtual try-on
- New product ratings
- Automatic return decisions
- Seller penalties
- Price prediction
- Chatbot functionality

These can be considered only after validating the core problem.

---

## MVP Success Criteria

The MVP should answer one question:

> Can ReviewLens help shoppers understand the most important product
> experiences faster than manually scanning reviews?

If this cannot be demonstrated, additional features should not be
prioritised.
